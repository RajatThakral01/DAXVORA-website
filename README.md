# DAXVORA Brand Kit

## Core idea

**Data first. Agents next.** DAXVORA builds the trusted data foundation and then adds the agentic operating layer.

## Logo

The primary logo is a plain, bold uppercase wordmark. Do not add gradients, circuit patterns, outlines, shadows, or an AI-brain symbol. Use the DX monogram only where the full wordmark is too small.

## Color

- Carbon `#0B0D10`: primary type and dark backgrounds
- Bone `#F4F2EC`: warm document and presentation background
- Signal `#C8FF3D`: status, cursor, key rule, or one small emphasis
- Graphite `#343941`: secondary text
- Mist `#E6E9ED`: rules, dividers, and quiet fills
- White `#FFFFFF`: reversed wordmark and clean surfaces

## Typography

- Wordmark: Arial Black, uppercase, modest tracking
- Documents: Arial; Arial Bold for hierarchy
- Voice: direct, operational, evidence-led

## Document rules

1. One page, one job: understand, decide, or act.
2. Titles are direct statements, not vague labels.
3. Use compact metadata, thin rules, and generous whitespace.
4. Use Signal sparingly; it is a functional state color.
5. Tables are for comparison and status, not for packaging paragraphs.

## Working descriptor

The data and agentic operating layer for business.
